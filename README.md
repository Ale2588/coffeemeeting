# CoffeeMeeting — React prototype

Prototipo Vite + React ricostruito a partire dal materiale di design fornito.

## Avvio locale
1. Installa Node.js 20+.
2. Apri un terminale nella cartella del progetto.
3. Esegui `npm install`.
4. Esegui `npm run dev`.
5. Apri l'indirizzo locale mostrato da Vite.

## Struttura
- `src/main.jsx` — interfaccia e flussi demo
- `src/styles.css` — stile visuale
- `index.html` — entrypoint Vite
- `package.json` — dipendenze e script

Le integrazioni Supabase, Stripe e Resend non sono ancora collegate: questa consegna è il prototipo frontend navigabile.
